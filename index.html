What's Actually In It

Built as a single-file FastAPI app — the model narrates, the backend decides.

Two Voices, One Broadcast

A snarky game-show announcer and your deeply unimpressed cat companion react to every turn — narration only, no invented numbers.

Deterministic Combat

Hit chance, damage, crits, loot, and XP are all resolved by plain Python before the model ever sees the turn. The LLM can't drift your stats.

Full Character Panel

Level, XP, HP/mana, five stats, equipped gear, inventory, skills with cooldowns, and stacking curses/boons.

3 Floors, Each With a Boss

Two regular encounters and a boss fight per floor, plus a Sponsor Booth shop between floors for gear and a free risk/reward pull.

A Cat That Actually Helps

Beyond banter, the cat lands a small automatic assist hit most rounds — no mana or turn spent.

Progress Autosaves

Every turn writes to a save file, so a server restart resumes your run instead of wiping it.

How to Run It Locally

It's a single Python file. You'll need an OpenRouter API key.

  1. Clone the repo and move into it.
  2. Create a file called env.txt in that folder with one line: OPENAI_API_KEY=your_openrouter_key_here
  3. Install dependencies and start the server.
  4. Open the app in your browser.
git clone https://github.com/firekarrde/DCC.git
cd DCC
pip install fastapi uvicorn openai python-dotenv

echo "OPENAI_API_KEY=your_openrouter_key_here" > env.txt

uvicorn dungeon_app:app --host 0.0.0.0 --port 8000
# then open http://localhost:8000
